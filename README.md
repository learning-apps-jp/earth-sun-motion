# 地球と太陽の一日

`node server.cjs` で起動し、http://localhost:8791 を開きます。dist/index.html を直接開いても利用できます。外部ライブラリ・通信・カメラは不要です。

再生・一時停止、一日のスライダー、日の出・正午・日の入りへの移動、再生速度に対応。クイズ・チャレンジ・逆回転実験はありません。

## iPad向け表示

横向き（幅1000px以上）は宇宙と地上を横並び、縦向きは上下に配置。ボタンは44px以上、スライダーは44pxの操作領域を確保しています。宇宙の大気光・球面陰影・雲、地上の海と山並み・太陽の反射をSVGで描画します。外部画像の読み込みはありません。

「方角を表示」で、赤い観察者に対する東西南北を表示できます。北は北極方向、南はその逆、東は反時計回りの接線方向、西はその逆です。上空からの模式図への投影であり、北・南を画面全体の固定した上下として示すものではありません。

地球を指またはマウスで円を描くようになぞると、触れた位置からの移動量で地球を回せます。再生中に触れると一時停止し、離した位置を保持します。地上の太陽・方角・スライダーも連動します。時計回りになぞると時間を戻せます。地球の外ではページを通常どおりスクロールできます。

`node check.cjs` で連動・再生・停止と、日の出・正午・日の入り・夜における方角を確認できます。

北極から見た反時計回りの自転と、南向きの空（左が東、右が西）を連動表示します。春分・秋分ごろの日本付近を想定した模式図で、季節・緯度・大気差や正確な天体位置は計算しません。時間スライダーは等分した一日の目安で、正午は時計の12時ではなく南中を意味します。
